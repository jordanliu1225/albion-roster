🔒 隊長登入

只有負責排名單的人需要登入,其他人打開網頁就會看到即時名單。

  1. 開啟 GitHub 建立權杖頁面(Fine-grained token)
  2. Repository access 選 Only select repositories → 勾 albion-roster
  3. Permissions → Repository permissions → Contents 設為 Read and write
  4. 按 Generate token,把產生的權杖貼到下面

權杖只存在這台電腦的瀏覽器裡,只用來把名單寫進 GitHub。

📥 貼上 Discord 名單

直接貼上 Discord 那份「武器 - @名字」清單,會照順序填進每個位置;也可以一行一個名字。
